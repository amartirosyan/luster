# Luster

Luster.show is a Google Photo player for LG TVs.

The live site is [lustre.show](https://lustre.show). The current build is **1.2.14**.

`LUSTRE.md` is the handoff for the bot that maintains this repo: version rules, motion, blur, pairing, and how the television package is built.

The television app lives in `public/tv`. The site is the TanStack app in `src`.
